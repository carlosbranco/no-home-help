Homeless and housing-crisis help in Layton

Immediate danger, serious injury, overdose, fire or a crime in progress: call 911. Mental-health or substance-use crisis: call or text 988. Community referrals: call 211.

Last verified: 2026-11-25

Davis County's general warming center opens only on officially activated Code Blue nights. Year-round shelters are regional or serve specific groups. Call before travelling. No listing guarantees a bed, room, housing, appointment, benefit, payment, treatment or job.

For a cold-weather night, check the current Davis County Code Blue status first. Families with minor children have a separate Open Doors route. Outside Code Blue, ask Open Doors or 211 about regional shelter in Ogden or Salt Lake County, and state any transport, pet, health, safety or accessibility needs.

Shelter and housing access

Davis County Warming Center — Code Blue nights only

Overnight cots and warmth for unsheltered adults only when Davis County officially activates Code Blue because of extreme cold or weather. It is not a year-round shelter. Pet admission depends on capacity and behaviour, with no more than one animal per household.

Talia's Event Center, 22 E 200 S, Clearfield, UT 84015

8014513495

daviscountyutah.gov/ced/grants-and-community-development/code-blue

Active Code Blue nights only, 19:30–07:30, during the seasonal period

Confirm activation before travelling. Adults may arrive at the center; ask the county about free UTA passes. Bring essential medication and disclose any accessibility need.
